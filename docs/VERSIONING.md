# バージョン管理方針

## 初期バージョン

このアプリは `v18.7` を初期バージョンとします。

## 採番ルール

- `v18.8`: 既存機能と互換性のある機能追加・改善
- `v18.9` 以降: 同じ世代での機能追加・改善
- `v19.0`: 大きな仕様変更、データ形式変更、または互換性を壊す変更
- ドキュメントのみの変更ではバージョンを上げない

## リリース手順

1. 機能ごとに `feature/`、`fix/`、`refactor/` ブランチを作成する
2. 動作確認後、`main` へのプルリクエストを作成する
3. `main` にマージしたコミットをリリース対象にする
4. `VERSION`、`CHANGELOG.md` を更新する
5. `v18.8` や `v19.0` のGitタグとGitHub Releaseを作成する
6. GitHub Pagesの公開状態を確認する

リリース用タグは、リリース対象のコミットを固定するために使用します。タグとReleaseは、完成した状態を `main` にマージした後に作成します。
